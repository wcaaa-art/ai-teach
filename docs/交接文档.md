## 一、5 分钟跑起来

```powershell
npm install
Copy-Item .env.example .env     # 然后把 DEEPSEEK_API_KEY 换成你自己的 key
npm run dev                     # 同时起 vite(5173) 与 Express(3001)
```

- 打开 `http://localhost:5173`。
- 后端存活检查：`http://localhost:3001/api/health` 返回 `{"success":true,...}`。
- **没有密钥也能跑**：摸底题、章节测试、计划、答疑都会降级到本地题库/本地规则，课程目录、专注计时、IndexedDB、看板不受影响。需要真实 AI 能力时再配 key。
- Node 20 LTS 可运行，建议 22 LTS。
- 5173 / 4173 都在 `vite.config.js` 里设了 `strictPort`，端口被占会直接报错，不会偷偷漂到 5174。
- `server/` 没有热重载，**改后端或提示词必须重启** `npm run dev`（或单独重启 `npm run dev:server`）。

其它命令：

| 命令 | 用途 |
| --- | --- |
| `npm run dev:client` | 只起前端（会提示「后端服务器未连接」） |
| `npm run dev:server` | 只起后端 |
| `npm test` | `node --test`，当前 61 项全绿 |
| `npm run typecheck` | 渐进式 TS 检查（`// @ts-check` 标注的文件） |
| `npm run build` | 生产构建，约 29 秒 |
| `npm run mcp` | 以 stdio 启动 MCP 服务 |
| `npm run rag:build` | 重建 RAG 真题索引（需要本机 Python + PyMuPDF） |

## 四、数据在哪里

### 浏览器 IndexedDB（主存储）

v5 共 14 张表：`profile`、`plans`、`focusSessions`、`distractions`、`feedbacks`、`assessments`、`visualLogs`、`conversations`、`settings`、`quizFingerprints`、`quizResults`、`focusSuggestions`、`examScores`、`mistakes`。

- **账号分库**：未登录用 `ai-teach-local`，登录后用 `ai-teach-user-<服务端用户 id>`；`setDataOwner()` 切换连接。
- `settings` 固定读写本地库，设备偏好不跟账号走。
- 登录时若本地有学习记录，会问是否同步；**同步 = 迁移**（复制到账号库后清空本地业务表，`clearLocalLearningData()`），避免重复提示和串号。
- 退出登录切回本地库。

### 服务端

- `server/data/`：`users.json` + `session-secret`，首次启动自动创建，已被 `.gitignore` 忽略。**不要提交，不要打进任何压缩包。**
- 学习数据不在服务端，服务端只存账号与会话。

### 两条硬规则

1. 写 IndexedDB 前必须把 Vue 响应式代理转成普通对象（`JSON.parse(JSON.stringify(...))`），否则 `DataCloneError` 会被静默吞掉，表现为刷新后数据全丢。
2. 所有入库字段必须是 JSON 兼容类型，时间统一用 `Date.now()` 数字，不要写 `Date` 对象或函数。

## 五、AI 链路（改之前先看这里）

1. **摸底**：按题位逐题并发请求，合并后由 `stampDiagnosticQuestionIds()` 重发唯一 id `diag-<位>-<时间戳>`。模型固定返回 `id:"q1"`，不重发会导致所有题共用一个答案键（历史 bug）。
2. **计划两段式**：先 `/plan/skeleton` 用本地 `buildAdaptivePlan` 出骨架（`aiPending: true`）立刻跳结果页，再请求 `/diagnose` 合并 AI 文案。合并按 `planMergeKey`（章节 + 阶段）匹配，**不能按数组下标**，因为 `orderCurriculumPlans` 会重排。
3. **章节测试**：蓝图展开成逐题位，`QUIZ_CONCURRENCY = 6` 限流并发，单题超时 20 秒，失败题位用本地兜底补，`stemHash` 做 7 天去重。
4. **答疑**：`/tutor/stream` 逐 token 产出 `thinking / token / tool / done / fallback`，前端 `AgentTrace` 展示工具步骤；`tutor`（图片）仍是一次性请求。
5. **RAG**：`rag_knowledge_query` 返回课标知识点 + 真题片段，BM25 + 同题去重，索引文件 `server/rag/rag-index.json.gz` 已入库。
6. **超时口径**：前端超时必须大于后端（摸底后端 90s / 前端 95s，计划后端 70s / 前端 75s），否则前端先断、结果无处可回。
7. **降级原则**：无密钥、超时、模型返回不合法，一律回落本地题库/本地规则，不允许白屏或功能全挂。

## 八、已知坑（省时间的部分）

- `node server/index.js` 没有 watch，改完必须重启。
- 端口被占 Vite 会直接退出，先看 5173 / 3001 是否被旧进程占用。
- 摄像头需要 `localhost` 或 HTTPS 安全上下文，否则拿不到媒体流。
- PowerShell 写提交信息：`git commit -m "$(cat <<'EOF' ...)"` 不支持，中文会乱码。用 `Write` 写 UTF-8 文件后 `git commit -F 文件`。
- `npm test` 会递归扫描子目录里的测试文件，仓库里不要再放源码副本（曾有 `传智杯提交包/项目源码/` 导致测试跑两遍）。
- ECharts 雷达首次渲染没有过渡动画，`ChartPanel` 的 `animateIn` 用「先写零值、下一帧再 merge」实现。
- 前端在 801–1120px 只显示导航图标；窄屏布局改动要按 1440 / 1024 / 801 / 800 / 375 逐档看。
- `formatMathText` 的向量箭头样式必须放全局 `styles.css`，`scoped` 对 `v-html` 不生效。
- 摸底历史记录若 id 重复（修复前的旧数据），报告页会显示黄色 `legacy` 警告，属预期，不是新 bug。
- 页面刷新时先等 `ensureAuth()` 完成再渲染，避免先用本地库渲染再切账号库。

## 九、协作规范

- 中文注释、英文标识符；沿用现有 Vue / Element Plus 风格，不擅自改主题和布局。
- 外科手术式改动：只改必须改的，不顺手重构，不删别人写的「看起来没用」的代码（先问）。
- 提交前至少跑 `npm test`；动了构建配置或大组件再跑 `npm run build`。
- 提交信息中文，前缀用 `feat:` / `fix:` / `perf:` / `docs:`。
- 构建产物 `dist/`、截图、日志、压缩包不进仓库；`.env`、`server/data/` 永远不提交。
- 新功能完成标准要可验证：跑了测试、构建，或者实际在浏览器走过一遍，再报完成。
