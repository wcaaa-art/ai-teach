# 商业路径与竞品对标

> 一页纸版本，用于答辩与评审问答。所有数字来自项目实测（`npm run rag:eval`、`npm test`），不写没有依据的估算。

## 一、我们卖的是什么

**不是"一个 AI 问答框"，而是一套跑在学生自己电脑上的自适应学习闭环。**

| 环节 | 产品能力 | 对应技术 |
| --- | --- | --- |
| 诊断 | 专题摸底、按知识点给掌握度 | Agent 出题 + 结构化校验 |
| 规划 | 四阶段任务（概念→例题→迁移→复盘）+ 艾宾浩斯复习间隔 | 规划 Agent + MCP 工具 |
| 执行 | 番茄专注、摄像头注意力监督、错题重做、文科背诵 | MediaPipe / Whisper / OCR 全本地 |
| 复盘 | 错题归因、知识点聚类、AI 周报 | RAG 检索 + 数字一致性校验 |

## 二、两条商业路径

### B 端优先：学校 / 教培机构（主攻，付费意愿最明确）

- **私有化部署**：整套服务（前端 + Express + 题库 + RAG 索引）可离线交付到校方机房，**学生数据不出校**。
- **卖点**：① 数据合规——语音、图像、专注记录全部本地推理，不上传；② 零外网依赖——弱网校园网照样能用；③ 可对接教务系统：错题库、掌握度雷达、计划完成率都是现成的学情数据。
- **交付形态**：一次性部署费 + 年度维护（题库更新、模型升级、教研对接）。
- **为什么学校会买**：现在学校用的大多是"题库 + 打卡 App"，有数据但不闭环；我们要补的是**从数据到下一周计划的闭环**，而不是再卖一套题。

### C 端辅助：家长/学生订阅（次要，验证口碑）

- **形态**：单科订阅（例：数学自适应包，含知识点图谱 + 每周计划）。
- **关键**：C 端不追求功能多，追求**打开就能用、不用配置**。本项目已具备（`npm run dev` 一条命令、摄像头默认关闭、模型离线加载）。
- **获客**：走内容与口碑（错题归因、知识点归纳本身就有传播性），不做投放。

## 三、竞品对标

| 方案 | 短板 | 我们的差异 |
| --- | --- | --- |
| 通用 AI 问答（DeepSeek / ChatGPT 客户端） | 不懂教材体系、不留学习数据、无法形成计划 | 内置课标 + 教材版本 + 真题 RAG，输出可执行计划并沉淀学情 |
| 传统教辅 App / 题库 | 只做题，不知道"你为什么错"、不安排复习节奏 | 错题自动归因到知识点 + 间隔复习 + 计划闭环 |
| 在线 AI 辅导（一对一） | 贵、无法覆盖日常、依赖稳定网络 | 7×24 本地可用，单机即可运行，边际成本接近零 |
| 番茄钟 / 打卡类专注工具 | 只有计时，不理解在学什么，也不给反馈 | 注意力监督 + 任务绑定 + 走神归因 + 学情回流 |
| 通用多模态大模型 | 音频与图像要上云、成本高、未成年人数据外流 | Whisper/OCR/MediaPipe 全本地，音频与图像不出本机 |

**一句话差异**：别人把 AI 当成一个聊天框，我们把 AI 当成一个**会自己排课的老师**——它知道你学了什么、错在哪、下周该练什么。

## 四、社会价值落地

1. **弱网与低配可用**：语音识别、视觉检测、OCR 全部在浏览器本地跑，模型随项目分发（`public/models`），不需要下载几十 MB 的云端 SDK。
2. **缩小城乡差距**：一台普通笔记本 + 离线包即可获得完整的自适应学习闭环，不依赖名师与优质课程资源。
3. **保护未成年人**：摄像头默认关闭、需主动授权、视频帧不出本机；AI 不做心理诊断、不给学生贴"懒惰""不自律"标签（已写入周报提示词并由契约测试守护）。
4. **不制造焦虑**：周报只描述行为和结果，不排名、不比较；错题消灭率、连续学习天数等指标都以学生自身历史为参照。

## 五、可持续性

- **模型成本可控**：DeepSeek 密钥缺失时全链路降级到本地题库与本地规则，功能不中断——这既是可用性设计，也是成本设计。
- **内容成本可控**：题库与真题索引离线构建（`npm run bank:build`、`npm run rag:build`），一次构建长期复用。
- **可扩展**：核心能力已封装为 MCP 标准工具（`npm run mcp`），可被外部 Agent 直接接入，不必重写。

## 六、评审可能追问的回答

**Q：数据都在本地，那模型效果怎么保证？**
A：模型负责推理与语言组织，**关键事实一律来自可溯源的数据**：课标知识点（教材目录）、真题片段（RAG，出处用原卷名）、学习记录（本地数据库）。周报生成后还会跑一遍数字一致性校验，模型写出的数字若在学习数据里找不到，会在界面上直接标出来。

**Q：摄像头盯着学生，家长会不会反感？**
A：默认关闭，必须主动授权；视频帧不离开浏览器，只在本地算出"是否在岗、是否低头"这类状态量。而且我们**不做心理评价**，只记录行为，评审可现场验证帧不外传。

**Q：和 ChatGPT 客户端比，值在哪？**
A：ChatGPT 每次对话都从零开始，我们有跨周期的学情记忆：错题、掌握度、专注节奏都沉淀在本地，模型每次都在这些数据上做决策——这是"聊天"和"教学"的差别。
