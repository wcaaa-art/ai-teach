## 三、AI 能力页（`/ai`）

### 3.1 入口与路由

- 新路由 `/ai`（name `ai-lab`，懒加载 `AiLabView.vue`）。

- 首页 hero 新增「AI 能力」入口。

### 3.2 后端接口

| 接口 | 作用 |
| --- | --- |
| `GET /api/ai/capabilities` | 模型名、Agent 工具、MCP tools/resources/prompts、RAG 状态与评测用例数 |
| `GET /api/ai/rag-search?q=&grade=&subject=` | BM25 现场检索，返回 topics + 前 3 条原文片段（含出处、年份、分数、耗时） |

- 新增 `server/mcp-capabilities.js`：把 MCP 元数据从 `server/mcp.js` 抽出，MCP 服务与能力页共用一份数据源，避免文案漂移。
- `src/services/api.js` 新增 `getAiCapabilities()`、`searchRagPassages()`。

### 3.3 页面结构（`AiLabView.vue`）

1. Hero + 实时状态卡（模型 / RAG / MCP / 4 个 Agent 工具 / 23 条评测用例 / 5 条多模态通道）
2. 五步学习闭环
3. RAG 现场检索（4 个快捷问题 + 话题 chip + 原文片段卡）
4. Agent 四工具卡片
5. MCP 三栏 + 可复制 `mcpServers` 配置
6. 多模态五通道 + 五道可控护栏
7. Local First 收尾

> 页面数据全部读后端真实状态；后端不可达时才使用内置兜底常量，不白屏、不放假动画。

### 3.4 修复的问题

- PDF 原文含 PUA 私用区字符，摘要被误判乱码 → 剥离 PUA、在 `【答案】` 前截断，保留摘要并标记 `garbled`。
- 「二次函数顶点式」检索会混入农业题 → 增加 2-gram 关键词过滤，只保留相关片段。

## 四、全站视觉统一「薄雾青」

### 4.1 设计方向

安静的学习桌面：低饱和青绿主色 + 极小面积暖沙点缀，不用彩虹色、荧光色和大字号炫技。所有页面共用一套 token，不各写各的。

### 4.2 全局配色（`src/styles.css`）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f2f7f5` | 页面底色 |
| `--surface` | `#ffffff` | 卡片纸面 |
| `--surface-soft` | `#f6faf8` | 次级块 |
| `--text` | `#22322f` | 墨绿正文 |
| `--muted` | `#5f736e` | 弱化文字 |
| `--primary` | `#4d817a` | 主色（按钮 / 链接 / 强调） |
| `--primary-soft` | `#e7f1ed` | 主色浅底 |
| `--accent` | `#c09a70` | 暖沙（仅小面积） |
| `--border` | `#e0eae6` | 分隔与描边 |

Element Plus 主色与成功 / 警告 / 危险 / 信息色全部同步降饱和，对错仍可分辨，但不再荧光。

### 4.3 统一记号：眉标

- 全局 `.eyebrow` 统一为「一枚 5px 细点 + 疏排中文」（`letter-spacing: .18em`）。
- 各页原本混用的英文大写标签全部换成中文：
  - `LEARNING INSIGHTS` → 学习数据
  - `NEXT STEP` → 下一步
  - `AI WEEKLY REPORT` → 每周复盘
  - `CHAPTER QUIZ` → 章节测试
  - `AI STUDY COPILOT` → 多模态答疑
  - `MCP / AGENT TOOLS` → MCP 协议 / Agent 工具
  - 其余页面同理

### 4.4 排版与版式

- 标题字重从 800 降到 600；`page-title` 统一 30px、副标题 14.5px / 行高 1.8。
- 首页 hero 标题从 59px 收到 `clamp(32px, 3.4vw, 50px)`，学习地图卡取消 `-3°` 倾斜。
- 卡片圆角统一 18px，阴影改为低透明大扩散（`--shadow`）。
- 导航 SVG 图标取消彩虹色，统一 `currentColor`，仅激活态用主色。
- 字号仍走 `--fs-scale`，保留全站 1.1 倍放大，不影响原有可读性调整。

### 4.5 各页面板对齐

| 页面 / 组件 | 调整 |
| --- | --- |
| 首页科目卡 | 五种彩虹色 → 同一支青绿的明度档；化学 / 语文不再用米黄 |
| 首页 CTA | 深蓝绿底 + 橙色按钮 → 深青底 + 暖沙按钮 |
| 导航 | 彩色线性图标 → 统一弱化色，激活主色 |
| 学习看板 | 图表配色改 `#4d817a / #9cbfb7 / #a7c8bf / #c09a70 / #b96b63` |
| 学情诊断 | 三张入口卡收紧间距，装饰圆环减弱 |
| 学习计划 | `--plan-*` 色板对齐；「一句话实话」米黄 → 浅青绿 |
| 专注空间 | 本地深绿体系对齐全局主色；标题 46px → 33px |
| 练习 / 背诵 | 本地变量对齐全局 token |
| 错题库 | 标题字重与字号统一；计时胶囊改 token |
| AI 能力 | 蓝色引用 chip / 分数 → 主色；英文眉标改中文 |
| 答题引用 / 来源徽标 | 蓝色 chip → 青绿 chip |
| 登录页 | 英文眉标改「你的学习空间」；标题 52px → 44px |

### 4.6 深色模式修复

- 修复 Vue scoped CSS 陷阱：`:global(:root[data-theme='dark']) .plan-page{...}` 会被编译成只剩 `:root{...}`，导致深色覆盖静默失效；必须写成 `:global(:root[data-theme='dark'] .plan-page){...}`。
- 补深色色板：首页科目卡、诊断入口卡、专注页（纸面 / 时长 chip）、计划页、练习 / 背诵页。
- 全局深色 token 改为绿调深色（`--bg:#132320`、`--surface:#1b2d29`、`--primary:#7fb5ab`）。

### 4.7 移动端

- 首页隐藏装饰浮卡，避免压住地图卡标题。
- 全站 390×844 无横向溢出，底部 Tab 栏图标统一弱化色。
