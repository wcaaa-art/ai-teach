# 本地启动、依赖、调试与测试清单

## 环境要求

- Node.js 20 LTS 或更高版本，npm 10 或更高版本。
- Chrome、Edge 或 Firefox 的近期桌面版本。摄像头要求 HTTPS 或 `localhost` 安全上下文。
- 端侧 OCR 首次使用需要下载 Tesseract.js worker 与中文/英文语言数据；MediaPipe 首次启用需要加载浏览器侧模型资源。网络不可用时相关能力会温和降级。
- 背诵学习窗的语音识别是纯本地 `whisper-tiny`：模型与推理内核随仓库放在 `public/models/Xenova/whisper-tiny` 与 `public/ort`（约 70MB），运行时只读本地文件、不访问外网，因此 `npm run build` 产物约 140MB。首次进入背诵页会加载模型（数秒），麦克风权限被拒时自动切换成打字核对。

## 安装与启动

```powershell
# 在项目根目录执行
npm install
Copy-Item .env.example .env
```

打开 `.env` 并填入个人 DeepSeek API key：

```dotenv
PORT=3001
CLIENT_ORIGINS=http://localhost:5173,http://localhost:4173
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL_NAME=deepseek-flash
DEEPSEEK_API_KEY=【TODO：填写服务端密钥】
VITE_API_BASE_URL=/api
```

前后端同时热启动：

```powershell
npm run dev
```

浏览器访问 `http://localhost:5173`；Express API 默认运行在 `http://localhost:3001`。单独启动可执行 `npm run dev:client` 或 `npm run dev:server`。构建与预览：

```powershell
npm run build
npm run preview
```

### 提示「后端服务器未连接」怎么排查

1. 确认 3001 在监听：`Get-NetTCPConnection -LocalPort 3001 -State Listen`，没有输出就是后端没起。
2. 直接访问 `http://localhost:3001/api/health`，正常应返回 `{"success":true,...}`。
3. 只跑了 `npm run dev:client`：另开一个终端执行 `npm run dev:server`，或直接用 `npm run dev` 同时起两个服务。
4. 3001 被旧进程占用：结束占用进程后重新启动；端口冲突时后端会在控制台打印 `EADDRINUSE`。
5. 改动 `server/` 下的代码、提示词或题库后必须重启后端，Express 不会热重载。

后端单元测试：

```powershell
npm test
```

## 调试指南

1. **页面打不开**：确认 Vite 5173 与 Express 3001 未被其他进程占用；检查浏览器控制台和终端输出。
2. **请求回到 mock**：浏览器开发者工具 Network 检查 `/api/agent/*`；访问 `/api/health`；确认 `.env` 中 key 未保留 `【TODO】`、模型名为 `deepseek-flash`、base URL 为 `https://api.deepseek.com`。服务端修改 `.env` 后重启 Node。
3. **摄像头无法开启**：使用 localhost/HTTPS；确认系统和浏览器权限；检查摄像头是否被其他应用占用。拒绝权限不影响页面切换监测和倒计时。
4. **视觉模型加载失败**：检查 CDN/模型资源网络与显卡支持；组件应显示降级说明。打开设置的低配模式可主动关闭视觉推理。
5. **IndexedDB 数据检查**：DevTools → Application/Storage → IndexedDB → `ai-teach-local`。清除站点存储会删除本机学习数据，演示前请先重置或准备干净浏览器配置。
6. **OCR 不可用**：确认允许语言 worker 下载；首次识别中文图片需要等待语言包；失败后可以在答疑框直接键入题目。
7. **通知不出现**：浏览器通知需要用户授权；部分操作系统会将通知静默呈现。提醒定时器只在当前页面/浏览器仍运行时触发。
8. **背诵页语音识别不工作**：Network 里应能看到 `/models/Xenova/whisper-tiny/**` 与 `/ort/ort-wasm-simd-threaded.asyncify.wasm` 全部 200；若 404，检查 `public/models`、`public/ort` 是否完整（这两个目录必须随仓库一起部署）。`vite.config.js` 的 `optimizeDeps.exclude` 已排除 transformers/onnxruntime，改回预构建会让 dev 启动失败。识别一直为空时先用「改成打字」核对内容是否正确，再确认麦克风音量。

## 手工验收测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| T01 | 新用户诊断 | 选择学段、年级、科目、专题和学习时间 | 看到课程专题与摸底入口；资料写入 IndexedDB |
| T01a | 专题摸底 | 选择专题，提交原创摸底题 | 掌握度按章节计算，生成顺序计划和桥接复习任务 |
| T02 | 信息缺项 | 通过 API 发送空科目或空薄弱点 | 返回 `needMoreInfo` 与缺失字段；不生成残缺计划 |
| T03 | 无 API key | `.env` key 保留 TODO 后提交诊断 | 自动生成演示计划，页面无崩溃，标记为 mock 来源 |
| T04 | 计划管理 | 编辑标签和时长、归档、恢复、删除 | IndexedDB 状态同步；重载页面后保留 |
| T05 | 浏览器提醒 | 为未来时间设置提醒并允许通知 | 计划保存提醒时间；在页面仍运行时触发通知 |
| T06 | 专注倒计时 | 开始、暂停、继续、手动结束 | 倒计时准确运行；结束打开反馈表单 |
| T07 | 切标签分心 | 专注时切换到其他标签并返回 | 自动暂停；新增一条 `tab-hidden` 本地分心记录 |

| T09 | 摄像头拒绝权限 | 同意隐私说明后拒绝浏览器权限 | 显示温和降级说明；倒计时与切标签检测继续运行 |
| T10 | 视觉 10 秒离岗 | 授权摄像头后离开画面 10 秒 | 提示音、温和弹窗、倒计时暂停；状态日志不包含图片 |
| T11 | 误判反馈 | 摄像头预览中点击“误判？” | `visualLogs` 写入 `false-positive` 状态与时间 |
| T12 | 视觉清理 | 摄像头开启时离开专注页或关闭开关 | 摄像头 track 停止、MediaPipe 模型关闭、视频帧回调停止、动画循环取消 |
| T13 | 答疑提示 | 浮窗连续短时间提问 | 频率限制提示；问答不跳出专注页 |
| T14 | 青少年答疑 | 要求给出完整作业答案 | 回复以思路提示/知识点引导为主；服务端过滤生效 |
| T15 | 语音与 OCR | 使用浏览器语音输入，选择题目照片 | 语音识别填入文本；Tesseract 在本地 OCR；照片不出浏览器 |
| T15a | 多模态答疑 | 在答疑页上传 JPG/PNG/WebP 图片并发送问题 | 图片随本次请求发送给 DeepSeek 视觉输入；会话历史只保存文字回复和问题 |
| T16 | TTS | 打开语音朗读开关并朗读答疑回复 | 浏览器语音播报；关闭设置后不播报 |
| T17 | 反馈计划迭代 | 完成专注并将掌握度设置为 0 或 1 | 反馈存入 IndexedDB；活动计划复习时间提前/优先级上调并写回 |
| T18 | 看板筛选 | 切换近 7/14/30 天 | 专注趋势和统计图根据筛选变化 |
| T18a | 3D 掌握图 | 完成摸底或反馈后打开看板 | 可旋转查看专题、学习顺序、掌握等级三维关系 |
| T19 | 主题/低配 | 切换深色主题、低配模式 | 主题持久化；低配模式不启用 MediaPipe 视觉推理 |
| T20 | Agent 工具续轮 | 使用可调用工具的有效 DeepSeek 配置 | 发送固定 tool schemas；续轮保留 `reasoning_content`、`tool_calls` 和 tool call id |
