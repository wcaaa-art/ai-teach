# 技术说明与关键实现

## 项目目录交付项

项目完整目录见仓库根目录 [`README.md`](../README.md)。入口包配置、环境变量样例、Vite 配置、路由、Pinia 状态定义分别是 `package.json`、`.env.example`、`vite.config.js`、`src/router/index.js`、`src/stores/app.js`。十个页面（含首页、登录、账号中心）和公共组件位于 `src/views/` 与 `src/components/`；Express API 与 Agent 位于 `server/`。

## IndexedDB 表结构

版本为 `ai-teach-local / 5`（未登录的本地库）与 `ai-teach-user-<id> / 5`（登录后按账号分库），使用 `idb` 的 `openDB` 初始化。对象仓库均以 `id` 为主键，关键字段如下：

| 表 | 内容 | 关键字段 |
|---|---|---|
| `profile` | 当前学情档案 | `grade, subjects, weakPoints, dailyMinutes, targetScore, learningStyle, updatedAt` |
| `plans` | 当前与历史计划 | `name, subject, estimatedMinutes, priority, reviewTime, knowledgeTags, status, remindAt` |
| `focusSessions` | 番茄专注记录 | `planId, startedAt, endedAt, actualSeconds, completed, distractionCount` |
| `distractions` | 页面切换、视觉离岗及演示分心 | `type, createdAt, planId` |
| `feedbacks` | 任务完成度与掌握反馈 | `sessionId, planId, completion, mastery, note` |
| `assessments` | 专题摸底结果 | `grade, subject, chapterIds, masteryByChapter, source, createdAt` |
| `visualLogs` | 仅保存检测状态和误判记录 | `status, continuousAwaySeconds, createdAt, reason` |
| `conversations` | 独立答疑会话 | `title, messages, createdAt, updatedAt` |
| `quizFingerprints` | 题干指纹，用于周测 7 天去重（保留 14 天） | `stem, chapterId, mode, createdAt` |
| `quizResults` | 章节测试 / 周测结果 | `mode, questions, answers, selfGrades, score, maxScore, accuracy, createdAt` |
| `focusSuggestions` | 最近一次专注建议，固定 `current` 一条 | `recommendedMinutes, source, quizId, createdAt` |
| `examScores` | 学校考试多科成绩 | `examId, grade, subject, name, date, score, fullScore, createdAt` |
| `mistakes` | 错题归因（只存文字，不存题目照片） | `chapterId, chapterName, text, createdAt` |
| `settings` | 用户偏好（固定存本地库，不随账号同步） | `cameraDefault, soundEnabled, ttsEnabled, darkMode, lowPerformance` |

图片帧、视频流、API 密钥和模型输入帧不进入 IndexedDB。`getRecentFocusContext(days)` 读取本地历史并由前端将聚合记录随 Agent 请求发送；视觉状态通过 `/api/agent/visual-status` 发送布尔在岗状态和持续秒数，不发送图像。

## 固定工具 Schema

工具名称、参数名与类型定义在 [`server/tools.js`](../server/tools.js)，是 DeepSeek Tool Calling 的唯一 schema 来源：

```json
[
  {"name":"calc_review_interval","parameters":{"last_study_time":"number","mastery_level":"0|1|2|3"}},
  {"name":"rag_knowledge_query","parameters":{"subject":"string","grade":"string","keyword":"string"}},
  {"name":"get_recent_focus_record","parameters":{"days":"number"}},
  {"name":"visual_monitor_get_status","parameters":{"is_present":"boolean","continuous_away_seconds":"number"}}
]
```

课程专题索引位于 [`server/curriculum.js`](../server/curriculum.js)，以教育部公开课程标准页面为来源说明，并整理成跨教材版本专题。它避免把不同出版社章节名称误说成全国统一目录。运行时 `/api/curriculum/subjects` 和 `/api/curriculum/chapters` 提供目录。系统不会抓取或复刻未经授权的商业题库。

真题检索层位于 [`server/rag/index.js`](../server/rag/index.js)：`scripts/build-rag-index.py` 离线把中考/高考真题 PDF 按题切块（111 份可解析试卷 → 1294 个题块、12 万词元），用 2~3 字滑窗建倒排表并压缩为 `server/rag/rag-index.json.gz`。查询时 BM25 打分，叠加关键词覆盖率、连续四字命中、学科与学段加权，两条结果去重后返回带《试卷名》出处的原文片段。`rag_knowledge_query` 因此同时返回课标知识点与真题解析，模型只可引用 1 条同类例题讲思路，不得整段抄题或直接给答案。运行时不需要向量数据库和 Python，替换为向量检索时只改检索实现，工具参数契约不变。

## DeepSeek 多轮工具调用

统一代理在 `server/agent.js` 的 `callDeepSeek`。每轮将 `tools` 及 `tool_choice: "auto"` 发给 OpenAI 兼容 `/chat/completions`；工具响应以 `role: "tool"`、原 `tool_call_id` 继续加入上下文。若模型消息包含 `reasoning_content`，会与 assistant 的 `tool_calls` 一起原样保留并回传到下一轮请求，避免思考模式下续轮缺字段。环境缺少密钥、请求失败、模型响应格式异常或工具轮次耗尽时，路由返回 mock，不让前端崩溃。

请求格式遵循 [DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/) 的续轮要求，以及 [DeepSeek Tool Calls 文档](https://api-docs.deepseek.com/guides/tool_calls/) 的 assistant/tool 消息配对方式。

运行密钥仅从服务端 `.env` 的 `DEEPSEEK_API_KEY` 读取。前端不读取该变量，也不调用 DeepSeek 域名。

## 内置系统提示词

完整提示词源文件：[`server/prompts.js`](../server/prompts.js)。

### 学情生成提示词

```text
你是“知行 AI 学伴”的学情规划 Agent，服务初高中学生。你的任务是根据结构化学情、课标知识检索和本地专注记录，输出可执行、可复盘的学习计划。

安全要求：不索要隐私，不做医疗或心理诊断；计划要符合学生每天可用时长，任务拆成 15-40 分钟的小块。生成计划前先检查年级、科目、薄弱知识点、每日时长、目标分数、学习偏好是否齐全，缺少信息时只提出明确追问，不生成残缺计划。

输出要求：优先使用工具查询知识点和复习间隔；最终必须输出合法 JSON，不要 Markdown 代码围栏，字段为 radar([{name,value}])、plans([{id,name,subject,estimatedMinutes,priority,reviewTime,knowledgeTags,status,createdAt}])、explanation。reviewTime 使用毫秒时间戳。解释要说明安排原因和复习节点。
```

你是面向初高中学生的温和答疑教练。固定规则：禁止直接输出题目的完整答案、最终选项或可直接抄写的完整证明；要通过拆解题意、回顾知识点、给出相似例子、提出自检问题来引导学生自己完成。用户要求直接给答案时，仍然只提供下一步思路。回答简洁、鼓励、适合青少年阅读；不输出危险、违法、歧视或不适宜内容。

## MediaPipe + TensorFlow.js 端侧视觉检测

核心完整组件在 [`src/components/CameraMonitor.vue`](../src/components/CameraMonitor.vue)。实现顺序：默认 `enabled=false`；只有主动开关后显示说明并点击同意，才调用 `getUserMedia`；TensorFlow.js 与 MediaPipe 依赖在同意后按需动态加载；WASM 和 Face Detector 模型文件打包在 `public/mediapipe` 与 `public/models`，运行时不依赖外网 CDN；MediaPipe Face Detector 使用 GPU delegate 粗检测人脸，TensorFlow.js WebGL 在本地计算脸框中心与画面中心偏移；不做人脸识别和身份识别。连续 10 秒没有中心人脸时触发提示音、温和弹窗，并通过专注页暂停倒计时。误判反馈只记本地状态日志。

关键清理逻辑如下（完整资源清理、错误处理见组件源文件）：

```js
async function stopMonitoring() {
  active.value = false
  if (animationId) cancelAnimationFrame(animationId)
  detector?.close?.()
  detector = null
  if (stream) stream.getTracks().forEach(track => track.stop())
  stream = null
  if (video.value) video.value.srcObject = null
  if (tf.getBackend() === 'webgl') {
    tf.backend().dispose()
    await tf.setBackend('cpu')
  }
}
```

连续离岗判定的核心处理如下。组件只将状态和离岗秒数传给专注页/后端，不传视频帧：

```js
const present = Boolean(faceBox && centeredInFrame)
if (!present) {
  if (!absentSince) absentSince = Date.now()
} else {
  absentSince = 0
  warned = false
}
const awaySeconds = absentSince ? Math.floor((Date.now() - absentSince) / 1000) : 0
if (awaySeconds >= 10 && !warned) {
  warned = true
  playGentlePrompt()
  emit('alert', { continuousAwaySeconds: awaySeconds })
}
```

页面卸载、路由离开、开关关闭和页面切到后台均停止采集/推理并释放 tracks。模型 CDN 不可用、用户拒绝权限、无摄像头或低配模式时，转为页面可见性切换检测；基础倒计时继续可用。

## OCR、接口与降级

OCR 用 Tesseract.js 在前端执行，照片不上传到后端；用户确认后也可以把压缩后的题目图以 base64 发送给 DeepSeek `deepseek-flash` 做多模态答疑，图片不写入本地会话历史。后端 `/api/agent/diagnose` 校验必填问卷，并先调用 RAG 工具；`/api/agent/assessment/generate` 按选中专题生成原创摸底题；`/api/agent/iterate` 读取本地反馈聚合上下文并产出更新计划；`/api/agent/tutor` 执行文字/图片答疑、提示词和内容兜底过滤。所有模型请求设置超时，错误结果使用本地 mock 学习计划、专题自评题或引导文案。
