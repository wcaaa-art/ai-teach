# AI 创新大赛交付材料

## 项目简介（约 300 字）

“知行 AI 学伴”是一款面向初中学生的 AI Agent 自适应学习规划与多模态专注自律平台。产品围绕真实学习过程构建闭环：学生提交年级、科目、薄弱知识点、可用时长、目标分数和学习偏好后，Agent 检查信息完整度，结合课标知识检索、复习间隔算法及本地学习记录，生成带优先级、预计时长、知识标签和复习节点的个性化计划。学习时，番茄倒计时支持全屏、切标签检测和可选端侧摄像头监督；视觉模块只判断是否在岗及头部大幅偏移，默认关闭，取得明确同意后才启用，视频流不离开浏览器。学生完成任务后提交完成度、掌握等级与备注，Agent 据此调整下一轮计划。所有学情、计划、专注、分心、反馈和答疑会话保存在本机 IndexedDB，无需账号；API 密钥只在后端环境变量中。平台提供 mock 降级和演示模式，让核心流程在网络、模型或摄像头不可用时仍可展示。我们希望用可信、温和、可解释的 AI 帮助学生把“想学好”变成每天可完成的一小步。

## 项目简介（约 1000 字完整版）

初中阶段的学习任务多、节奏紧，学生常常知道自己“哪里不太会”，却难以判断应该先学什么、学多久、何时复习；开始学习后又容易被页面切换、环境干扰或知识卡点打断。通用问答工具能回答单个问题，却很难持续理解学生的目标与过程，也无法将一次专注和一次错误转化成下一轮计划。针对这些问题，我们设计并实现“知行 AI 学伴”，定位为面向青少年的 AI Agent 自适应学习规划与多模态专注自律平台。

平台把学习闭环拆成六个互相连接的环节。第一，学情诊断页让学生先选择学段、年级、科目和跨教材版本的知识专题，再决定是否参加按专题生成的知识摸底。课程目录以教育部公开课程标准作为来源说明；摸底题由 Agent 生成原创题，服务不可用时回退到明确标注的本地示例题或自评题。第二，计划 Agent 调用课标知识检索工具，并参考艾宾浩斯复习间隔和本机近期专注统计，输出结构化任务列表与自然语言安排理由。每个任务包含名称、科目、预计时长、优先级、复习时间和知识标签，学生可以编辑、归档、删除或设浏览器提醒；跨专题时会插入灰色桥接复习任务。同一科目会以文件夹形式收纳，按知识顺序展开。第三，专注空间提供番茄计时、全屏和页面可见性检测。用户可主动开启摄像头监督，也可完全关闭摄像头，演示模式还能手动模拟离岗，保证答辩时不依赖现场设备。

视觉模块强调“最少必要检测”：默认关闭，打开前呈现明确同意说明；MediaPipe 在浏览器本地检测人脸框，TensorFlow.js 在端侧计算中心偏移，只判断是否在岗及头部大幅偏移，不识别个人身份。连续十秒检测不到居中人脸后，系统播放轻提示音、弹出温和提醒并暂停计时；用户可标记误判。视频帧既不上传云端，也不写入磁盘、不截图。离开专注页、关闭开关、切换后台或页面卸载时释放摄像头轨道并停止推理。设备性能不足、权限拒绝、模型加载失败时，系统降级到切标签检测和基础倒计时。

第四，任务结束后学生提交完成度、掌握等级和备注，数据进入 IndexedDB，并随下一次 Agent 调用作为上下文。Agent 根据反馈和近期状态调整任务时长、优先级与复习间隔，使计划在下一轮发生真实变化。第五，独立答疑页支持文字、语音输入、本地 OCR 和语音朗读；答疑会话与专注浮窗上下文隔离。内置青少年答疑规则禁止直接代写完整答案，重点是拆题、回顾知识点、提供相似例子和自检问题。第六，学习看板呈现每日专注趋势、完成率、分心与视觉离岗记录、知识点掌握进度，帮助学生看到长期变化，而不是只盯一次成绩。

工程实现遵循 Vue 3、Vite、Pinia、Element Plus、ECharts、MediaPipe、TensorFlow.js、Node.js、Express 和 IndexedDB 固定技术栈。浏览器端只调用自建 Express API；DeepSeek 的 API 地址、模型名和密钥通过 `.env` 管理，前端不接触密钥。Agent 采用 OpenAI 兼容 Tool Calling，工具 schema 固定为复习间隔计算、课标检索、近期专注记录、视觉在岗状态四类。多轮工具调用会保留并回传 `reasoning_content` 与 `tool_calls`，降低思考模式续轮报错风险。系统还提供统一超时、内容过滤和 mock 预案：模型余额不足、限流、接口失败、浏览器能力缺失时，页面不崩溃，计划、计时、反馈、本地持久化和答辩流程仍可运行。

我们的创新点不在于堆叠单一模型能力，而在于把“计划—专注—状态—反馈—再计划”连接成可持续运行的 Agent 流程；把摄像头使用权交还给学生，并用端侧计算减少敏感数据流动；把模型输出限定为结构化计划和学习引导，让结果可解释、可编辑、可追踪。后续可在保持工具 schema 和隐私边界的前提下，扩展经审核的课标知识库、更多设备端模型和教师授权的班级分析能力。

## 完整演示脚本（约 7–9 分钟）

### 1. 打开网站（30 秒）

台词：“这是知行 AI 学伴。它不止回答一道题，而是把学习计划、专注过程、状态反馈和下一轮计划连接起来。所有学情默认保存在本机，不需要注册。”指向侧栏六个模块，补充摄像头默认关闭。

### 2. 填写学情（60 秒）

在诊断页选择“初三、数学”，薄弱点填“二次函数、几何证明”，每日时长填 60 分钟，目标分数填 110，偏好选择例题驱动。台词：“系统先确保必需信息齐全，学生不需要一次就写完所有细节；缺项时会指出需要补充什么。”

### 3. 生成计划（45 秒）

点击生成。展示雷达图、Agent 安排解释和计划卡片。台词：“Agent 把知识点检索和间隔复习转成任务，明确任务时长、优先级和复习时间。模型不可用时会使用本地预设计划，演示流程不会中断。”

### 4. 开始专注和开启摄像头（60 秒）

进入计划页，选择专项任务并开始专注。展示全屏按钮与倒计时。开启摄像头监督，逐句读出弹窗中的隐私说明，再点击同意。台词：“摄像头由学生主动选择。这里处理的是人脸框是否在画面中间，不做身份识别；画面不上传、不保存。”如果现场不便开摄像头，切换演示模式并说明它可手动模拟相同的离岗事件。

### 5. 触发分心暂停（45 秒）

摄像头模式下离开镜头 10 秒，或在演示模式点击“模拟离岗”。展示温和提醒与暂停计时。台词：“系统不是惩罚学生，只是提醒并暂停计时。若出现误判，学生可以标记，误判反馈只记状态信息。”

### 6. 浮窗 AI 答疑（50 秒）

点击灯泡，问“二次函数顶点式怎么从图像上理解？”展示引导式回答。台词：“问答浮窗不离开专注页，有提问间隔保护；系统引导学生拆解知识点，不直接代写完整答案。独立答疑页还可以语音输入、题目照片本地 OCR 和语音朗读。”

### 7. 提交反馈并迭代（60 秒）

点击结束并反馈，完成度选 70%，掌握等级选 1，备注“顶点坐标会求，但最值应用还不熟”。提交后说明 IndexedDB 保存并触发 Agent 更新计划。台词：“一次完成情况会改变后续安排：掌握度较低时优先复习，掌握较好时拉长复习间隔。整个过程可以离线体验。”

### 8. 查看看板与收尾（45 秒）

打开看板展示专注分钟、完成率、分心和掌握度图表。台词：“看板呈现过程指标，帮助学生看到长期变化。我们用一个可持续、可解释、隐私优先的闭环，让下一次学习比上一次更有依据。”

## 评审高频问题与应答

### 为什么摄像头需要开启？会不会采集学生隐私？

摄像头是可选监督方式，默认关闭，必须经过明确同意。只在本地执行人脸在岗、头部朝向、闭眼与多人检测，不做人脸或身份识别；视频帧不上传、不写盘、不截图。关闭、离开专注页或切后台都会释放摄像头轨道。即使不开摄像头，页面切换检测和专注计时也完整可用。

### 模型接口失败或余额不足怎么办？

前端设置请求超时，后端统一处理非成功状态并返回本地 mock 学习计划或引导答疑。演示模式可以展示视觉离岗流程，IndexedDB 和倒计时在没有模型服务时仍能运行。

### Agent 如何真正“自适应”？

计划输入包括薄弱知识点、可用时间、学习风格和目标；反馈包括完成度、掌握等级、备注、专注时长、分心次数及视觉状态。Agent 根据这些上下文修改任务优先级、时长和下次复习时间，并写回本机计划库；掌握低时短间隔复习，掌握高时增加间隔。

### 为什么采用本地 IndexedDB？

项目面向未成年人，学习记录属于敏感个人信息。无登录和本地持久化减少不必要的账号与云端存储。需要调用模型时只发送规划所需字段和聚合学习状态，不发送视觉帧；API 密钥留在服务端环境变量。

### RAG 知识库目前是什么？

项目内置离线构建的中考真题索引：公开中考真题切成题块，用 BM25 + 学科/学段加权检索，`rag_knowledge_query` 返回可引用的原文片段与出处，答疑 Agent 在工具循环里先检索再回答。索引是构建期生成的 gzip 文件（约 1.9 MB），不依赖向量数据库；后续可在保持工具参数契约不变的前提下替换为向量检索。

### 如何避免 AI 直接给学生作业答案？

答疑系统提示词要求只拆解题意、提示知识点、给相似例子和自检问题；后端还有内容过滤兜底。计划生成与答疑上下文分开，答疑会话独立保存。

### 为什么选择 MediaPipe Face Landmarker？

MediaPipe 在端侧一次推理同时给出 478 个人脸关键点、眨眼 blendshape 和头部变换矩阵，前端自己算 EAR、yaw/pitch，并用 One Euro 滤波和状态机收敛成专注/分心/犯困/多人/离岗。全程本地执行、Apache 2.0 免费，不推断身份，也不生成身份模板；设备变慢时自动降到 BlazeFace 轻量模式。

### 如何证明它适合低配设备？

低配模式关闭视觉模型，只保留浏览器页面可见性事件和基础计时；模型加载失败也采用相同降级路径。运行全程不要求摄像头，视觉模型是额外可选能力。

### 后续如何衡量学习效果？

现阶段展示的是过程指标和掌握反馈，不宣称模型已经提高考试分数。后续可在取得学生与监护人授权、采用适当伦理与数据保护流程后，开展匿名化的长期可用性和学习效果评估。

### 深度思考模式的工具调用如何续轮？

每轮把 assistant 的 `tool_calls` 与 `reasoning_content` 放回同一个 assistant 消息，再追加带原 `tool_call_id` 的 tool 响应。工具 schema 固定，工具轮次有上限，异常会进入本地降级。
